# CodeAlpha_Sentiment_Analysis

## Task 4 – Sentiment Analysis

### Objective
Analyze customer reviews using Natural Language Processing (NLP) to classify sentiments as Positive, Negative, or Neutral and visualize the results.

## Tools Used
- Python
- Pandas
- TextBlob
- Matplotlib
- Seaborn
- WordCloud
- VS Code

## Dataset
- Customer Reviews Dataset (reviews.csv)

## Features
- Data Loading and Preprocessing
- Sentiment Classification (Positive, Negative, Neutral)
- Sentiment Count Bar Chart
- Sentiment Percentage Pie Chart
- Word Cloud Visualization
- Sentiment Score Distribution
- Review Length Distribution

## Key Insights
- Positive reviews formed the majority of the dataset.
- Neutral reviews were fewer compared to positive and negative reviews.
- Frequently used words such as "product", "battery", "great", and "excellent" appeared in the Word Cloud.
- Most sentiment scores were concentrated towards the positive side.
- Review lengths were generally moderate, indicating concise customer feedback.

## Conclusion
This project demonstrates how NLP techniques can be used to analyze customer opinions and visualize sentiment patterns. Such insights can support product improvement, customer satisfaction analysis, and business decision-making.
